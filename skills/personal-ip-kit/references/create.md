# 从参考图建立 IP

## 定位与结构

复用用户已提供的名称、用途、受众和风格。真实照片需要确认或合理建议转化风格；已有卡通形象默认延续风格，不能统一强制变成 3D。已有角色套装先检查并复用，不重复从零生成。

从实际图像记录固定特征。人物关注脸型、发型、眼镜、服装；动物关注毛色分区、斑纹、耳朵、口鼻、尾巴与体态；植物关注叶序、花瓣和茎；水果关注轮廓、果皮、蒂叶；物品关注外形、部件和标记。不要给所有主体套人物模板。

保留原参考的拟人化程度。要让无手的水果操作电脑，需要明确新的拟人化设计；若用户已授权自由设计，可选方案并记入 designAssumptions。不要把增加表情等同于允许新增人类手脚。动作应符合该角色的结构。

## 主参考先行

1. 建立独立档案，保存用户参考，整理固定特征、可变范围与设计补充。
2. 生成主设定板，包含完整主体与必要视角。原图约束身份，主板确定补全细节。
3. 检查主板。如果用户要求先看方案，交付主板等待反馈；若用户已授权完成整套，可以继续并标记为工作参考，不能冒称已获认可。
4. 根据用途挑选产物。完整套装可从头像、透明主体、四个常用表情或状态、两张场景与一张 Banner 起步；数量是建议，不强制凑数。无面部主体用状态或姿态。
5. 每张素材实际引用原始身份图与主板，单独生成与保存。复用已有可用资产时标记来源。
6. 检查固定特征与结构，写入手册和素材清单。整套交付使用打包流程。

## 主板或版本修改

用户改发型、服装、配件时，确认其意图是本次临时变化还是默认外观更新；上下文已明确则不重问。更新默认外观需要新版本主板与档案，保留旧版。后续新图引用新主板，旧素材不自动被改成新版本。

## 手册内容

用短文记录已确认定位、图像锚点、设计补充、可变范围、色彩与材质、比例、常用动作、文字与配角规则。仅把本角色实际需要的规则写入手册，不把当前案例的橙色外套、眼镜或其他个人特征写回通用 skill。
