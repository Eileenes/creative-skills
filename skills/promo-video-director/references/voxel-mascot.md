# 体素角色制作

仅在用户需要更换角色造型、附件或动作时读取。默认模板已经有鲸鱼，无需重新建模。参考代码位于 `../assets/mascot/voxel_mascot_reference.js`。它依赖 Onetake 的 OM 动作库，不是独立运行页面。

## 建模

- 用整数网格坐标，+x 朝向头部，y 朝上，方块边长 V≈0.088（鲸鱼全长约 1.45 个单位）。方块画成 0.93V 大小，留出缝隙，体素感才明显。
- 身体用超椭球：`(|y-cy|/hy)^p + (|z|/hz)^p <= 1`，p≈2.7；沿 x 方向的轮廓 `f = (1-|u|^3.2)^(1/3.2)`，尾部再收窄。
- **比例**：长度至少是高度的 2 倍。高度太高、尾鳍翘太高，从正面看会像海马或塔。
- 附件（尾柄、尾鳍、胸鳍）单独加，用 `part` 标记，之后好单独做动画。
- 只保留表面方块（6 个邻居里至少有一个是空的），能省掉大约一半。
- **配色**：品牌色做主体，每个方块亮度随机浮动 ±6%（用固定种子的 `OM.rng`），顶部稍亮，肚皮用浅色。
- **眼睛**：在侧面最外层选 2×2 的方块涂成深色，其中前上方一格涂白当高光。

## 动画

每次 seek 都把每个方块的矩阵重算一遍：

- **摆尾**：尾部方块绕支点旋转，`wag = sin(t·7.5)·0.22`，在空中时叠加更快的摆动。
- **眨眼**：眼睛方块在 y 方向缩到 0.15，持续 0.13 秒。
- **喷水**：头顶几个浅色方块向上冲再散开，持续 0.9 秒，次数要少，不然会像粒子特效。
- **跳跃**：`pos = lerp(a(t), b(t), ease) + sin(π·u)·h`；起跳前 0.07–0.14 秒下蹲；空中 y 方向拉长 12%，身体前后俯仰；落地用 `OM.impact` 压扁（sqx 0.22、sqy 0.3）。
- **朝向**：每段跳跃前 0.12 秒转向前进方向（用 `atan2(-dz, dx)`），停顿时转成 3/4 侧面对着镜头，用 sineInOut 过渡 0.2 秒。
- **拼成形**：每个方块从光标的世界坐标（先换算到角色本地坐标）用 `spring(t - t0 - dn·0.42, 0.62, 15)` 飞到自己的位置，dn 是到头部的归一化距离。
- **影子**：用一张径向渐变的平面代替真实阴影，跟着角色的朝向转；离地越高越淡、越大。
- 不要用 `Math.random`，一切都是时间的纯函数。
## 接入与验收

造型替换需要修改工作副本 comp.html 的 VOX 模型与相关动作；不能只改 mascot.preset 就声称换好了角色。保留 seek(t) 的确定性，检查侧面轮廓、落点、地面影子与镜头遮挡。先输出角色静帧，再接回完整时间线。
