# Soren · 个人 IP 品牌手册
版本：1.0 · 2026-10-23

## 品牌定位
Soren 是用户本人的卡通分身，面向普通用户和内容创作者，分享 AI 工具与实战创作。内容包括可复现教程、工具实测、工作流经验和失败复盘。

用户明确确认：名称 Soren、AI 工具与实战创作、普通用户和内容创作者、本人卡通分身。
用户随后授权直接完成整套 IP。以下视觉细节、性格、文案和配角定位由本次设计补齐，是可调整的设计方案，不冒称用户已逐项确认。

## 一句话介绍
**陪你把 AI 用起来，把想法做出来。**

账号简介建议：
> 我是 Soren，分享能跟着做的 AI 工具与创作实践。从一次尝试到一个作品，把步骤讲清楚，也把踩过的坑留下来。

## 角色性格与口吻
- 好奇、亲切、行动导向；先实测，再分享。
- 用具体步骤解释复杂概念，允许读者从零开始。
- 遇到错误能自嘲，随后指出可执行的解决办法。
- 分享验证过的成果；不编造测试经历、效果保证或工具能力。
- 常用句式：“先从这一步试起。”“这里我踩了个坑。”“跑通了，关键是这个设置。”
- 不把 Soren 写成无所不知的专家；不预设用户的真实年龄、籍贯或职业。

## 固定视觉识别
原始参考图和工作主参考由用户提供，不随本仓库分发。

- 暖色 3D 卡通青年男性观感，柔和圆润的脸型与大棕眼。
- 深棕色蓬松短发，大块圆润发束；黑色圆角方框眼镜和浓眉。
- 珊瑚橙／奶油白横条纹绒面衬衫式外套，奶油白内搭。
- 小型奶油白竖向胸章、深绿边框、上下排列的两个原图绿色竹节状符号；保留图形，不解释其既有含义。
- 全身采用约 4–4.5 头身的年轻创作者比例，以主参考实际轮廓为准。
- 深灰色宽松直筒裤，奶油白低帮鞋和小面积珊瑚橙拼色。
- 可见绒面与头发材质，暖而清晰的柔光；避免镜面塑料感、扁平日漫化或写实人脸。

## 颜色规范
以下为设计参考色值，不要求生成图的每个像素精确相等。

| 色彩 | 色值 | 用途 |
| --- | --- | --- |
| 珊瑚橙 | #FF7954 | 主识别、服装、重点与封面 |
| 奶油白 | #FFF5E8 | 背景、内搭、留白 |
| 深棕 | #3D281E | 发色、温暖的标题字色 |
| 炭灰 | #2D2B2A | 眼镜、裤装、正文 |
| 叶绿 | #5C7C3D | 胸章、成功状态、小面积辅助 |

背景优先奶油白或白色；橙色不必铺满每张教程图。红色只在错误提示或辣椒配角中少量使用。避免把大面积冷紫霓虹作为默认品牌色。

## 名称与标识
- 固定写法：Soren。
- 视觉识别优先由人物轮廓、眼镜、条纹和胸章共同承担。
- 封面字标使用圆润、清楚的无衬线文字；正文中文使用系统无衬线字体即可。
- 本套不新造与原胸章冲突的 Logo；不将其他创作者的 C 标志、耳机等符号移植过来。
- 图片默认无字；标题与长文案建议在排版层添加，以便编辑。需要图内文字时使用用户给定的短文案。

## 动作与叙事
| 状态 | 视觉行为 | 适用内容 |
| --- | --- | --- |
| 发现 | 抬眉、眼睛发亮、轻微惊喜 | 新工具、功能发现、开篇 |
| 思考 | 轻触下巴、目光关注问题 | 参数选择、原理、比较 |
| 遇到问题 | 稍显无奈、抓头或扶额 | 错误提示、避坑、复盘 |
| 跑通结果 | 开心举拳或分享结果 | 作品展示、教程结尾 |
| 讲解 | 一手指示／掌心引导明确对象 | 步骤说明、功能演示 |

单幅正式配图只讲一个核心意思。角色设定板是多视图用途的例外，不把每张正式插图都做成拼图。
同一个连续教程里，避免衣服、眼镜、发型、材质和人物比例漂移。

## 配角系统
- **VR 熊猫**：沿用原图黑白熊猫和橙边黑色 VR 眼镜。设计用途是体验新工具、好奇与陪伴。
- **辣椒／蒸笼**：沿用原图红辣椒、绿色蒂、眼睛与微笑、竹蒸笼。设计用途是轻微吐槽、提醒和“踩坑”情绪。
- 两个称谓是描述性工作名，不强行新增专有名字。
- 内容图按需要出现 0–1 个配角；品牌合照或封面可以同时出现。
- 不把这些元素解释为用户的地域身份。

## 素材与画幅
- 主设定板：多视图，可作为后续生成参考。
- 头像：1:1，人物正面；上传时预览平台的圆形裁切。
- 透明立绘：2:3；用于封面、幻灯片、网页和文章排版。
- 四种表情：单张 1:1 透明 PNG，各自独立可用。
- 教程配图：默认 16:9、少量象征性 UI、充分留白。
- 品牌封面：横版，包含 Soren 字标，避免堆叠长文案。
- 配角贴纸：独立透明 PNG。

实际像素尺寸与透明信息以 manifest.json 和验收记录为准，生成器可能不严格遵守请求画幅；有平台硬尺寸需求时另行适配，不把近似比例宣称成精确规格。

## 生成与修改方法
1. 读取本手册，查看原图和主设定板，至少把主设定板作为实际图像参考传给内置 image_gen。
2. 明确本图的一个核心动作与对象，沿用固定外观，写清构图、画幅和文字要求。
3. 单独生成每项资产；表情、头像、封面不挤在一张大图中。
4. 透明素材使用工具的 transparent_background=true；保存后检查 alpha 通道及边缘。
5. 检查身份、条纹与胸章、眼镜、手部、动作、文本和背景；发现问题时局部修改。
6. 保存到新的版本文件，保留原始图与主参考。
7. 图像生成能提高一致性，但不保证多次生成逐像素相同；高频使用优先复用本套已验收素材。

## 可直接使用的配图任务
- Soren 把零散的提示词卡片整理成清晰步骤，让新手看懂如何组织一个请求。
- Soren 在教程界面中指出一个错误参数，只突出一个修正点。
- Soren 展示刚完成的作品，一个干净的结果卡片与绿色成功标记。

项目内技能：.agents/skills/soren-ip-illustrations/
调用示例：
> 使用 $soren-ip-illustrations，画一张 Soren 发现提示词缺少输出格式的教程配图，16:9，不加文字。
