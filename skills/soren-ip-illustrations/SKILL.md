# Soren IP 配图
Soren 是用户本人的卡通分身，面向普通用户与内容创作者分享 AI 工具实战。名称大小写固定为 Soren。

## 统一参考

阅读本技能内的 [品牌手册](references/品牌手册.md)。原始脸部参考与主角色设定板不随仓库公开分发；创作前从用户提供的文件或用户授权的本地素材库中找到两张参考图。用户可以自行保存在工作目录中，避免把私人素材提交到公开仓库。

将实际参考图片路径传入内置 image_gen 的 referenced_image_paths。不要仅凭记忆或一段文字重建 Soren。原图决定脸部身份，主设定板决定新增全身细节。若参考缺失，先说明缺少哪一张图，不把别的角色或纯文字生成假称为同一 IP。

## 任务处理

- 一句话说明核心对象与动作即可开工，无须全文或重新进行角色访谈。只有确实无法判断本图要表达什么时才追问。
- 普通教程图默认横版 16:9，一图一个核心意思，角色实际参与操作、解释、排错或展示。
- 头像默认 1:1；表情和立绘根据用户用途使用真正透明背景。透明资产设置 transparent_background=true。
- 多个独立素材逐张生成与保存。只有用户要求设定板或联系表时才做多格布局。
- 优先复用现有可用素材；需要新场景时调用内置 image_gen。编辑既有图时先查看该图，并将它作为编辑目标引用。
- 不为普通请求改走 API／CLI；内置工具失败时如实报告可用状态。

## 不变特征与可变内容

锁定深棕蓬松短发、黑色圆角方框眼镜、暖色圆脸、珊瑚橙与奶油白横条纹绒面外套、奶油白内搭、绿边竖向胸章及原有双竹节状符号。全身用深灰长裤和奶油白／橙色低帮鞋。保持柔和、触感清晰的 3D 卡通风格。

按内容改变表情、动作、视角和道具。VR 熊猫及蒸笼辣椒是可选配角，普通内容图按需要选用，不必每幅都出现。不要据此推断用户真实年龄、职业或地域身份。

默认不生成文字。用户给定短文字时原样使用，较长标题建议留空位供排版。避免擅自加入第三方 Logo、其他创作者的人设或品牌符号。已有品牌封面可使用 Soren 字标。

## 验收与保存

查看结果，检查是否仍是同一角色、眼镜结构、条纹和胸章、动作是否传达核心意思、手臂与手指、文字和留白。透明图需检查真实 alpha；仅凭黑色或棋盘格预览不能断言有透明背景。遇到缺陷以明确的局部修改为先，修复两轮仍有明显问题时说明剩余问题并提供可用替代姿势，不无限重试。

新图保存到用户选定的工作目录；未指定时可用 `03-Assets/YYYY-MM-DD-soren-<主题>/`。用当前用户时区的日期；已有同名文件时递增版本。参考资产不复制成多套权威来源。同步保存本次提示词、使用的参考路径和简短验收结果，向用户展示图片及实际保存位置。

用户明确更改固定外观时遵循新要求，说明它将形成新版本，并同步维护主参考与手册，不能用旧规范否决用户变更。
